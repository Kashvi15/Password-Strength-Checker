# Password Strength Checker 🔐

A beginner-friendly Python project that checks password strength based on different criteria.

## Features
- Checks password length
- Detects uppercase letters
- Detects lowercase letters
- Detects numbers
- Detects special characters
- Calculates a password score out of 5

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed.
2. Open the terminal in VS Code.
3. Run the following command:

```bash
python password_checker.py
```

4. Enter a password when prompted.
5. View the password checks and score.

## Learning Goals
This project helped me practice Python conditionals, loops through characters, built-in string methods, and basic password validation.
